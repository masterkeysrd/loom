---
title: Choose a provider
description: Find a Loom integration for your runtime and credentials.
---

Start with the service or account you already use. Each guide covers authentication and a first request.

| I want to… | Start here |
| --- | --- |
| Run a downloaded model locally | [Ollama](./guides/providers/ollama.md) |
| Call a hosted model with an API key | [OpenAI](./guides/providers/openai.md), [Anthropic](./guides/providers/anthropic.md), or [Google Gemini](./guides/providers/google.md) |
| Sign in with an eligible ChatGPT account | [Codex](./guides/providers/codex.md) |
| Use a Claude Code or GitHub Copilot account | [Claude Code](./guides/providers/claudecode.md) or [GitHub Copilot](./guides/providers/copilot.md) |
| Connect to Google Antigravity | [Antigravity](./guides/providers/antigravity.md) |
| Classify or route input with a decision model | [TypeSafe AI](./guides/providers/typesafe.md) |

Once you can send a request, use the [model API guide](./guides/llm-package.md) to configure the model in your Go application.
