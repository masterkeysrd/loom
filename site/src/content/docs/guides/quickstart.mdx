Build a graph that takes a name and returns a greeting. It runs entirely on your machine and needs only Go 1.26.10 or newer.

## Create a Go module

In a terminal, create an empty project and add Loom's graph package.

```sh
mkdir hello-loom
cd hello-loom
go mod init example.com/hello-loom
go get github.com/masterkeysrd/loom/graph
```

## Add a greeting node

Save this program as `main.go`. The two edges tell Loom to start at `greet` and finish when that node returns its update.

<Code code={source.trimEnd()} lang="go" title="main.go" />

## Run the graph

```sh
go run .
```

You should see this greeting.

```text
Hello, Ada!
```

Change `s.Name = "Ada"` to `s.Name = "Sam"` and run the program again. The input update sets the starting state, the node fills in `Text`, and `result.State` contains the final greeting.
